# ok computer

App Flutter per organizzare materie e compiti nel calendario scolastico.

## App web

Il codice dell'app si trova in `mia_app/`. Il workflow GitHub Actions in
`.github/workflows/deploy.yml` compila e pubblica la versione web su GitHub
Pages a ogni aggiornamento del branch `main`.

Per abilitare la pubblicazione, apri **Settings → Pages** nel repository e
seleziona **GitHub Actions** come origine di build e deploy. Dopo il primo
deploy, il sito sarà disponibile all'indirizzo
`https://leoghisa2012-ui.github.io/ok-computer-/`.
